## 已同步的改动

- ModuleEndpoint 新增 beginPrepareForExit、isReadyForExit、cancelPrepareForExit。默认立即就绪；业务模块可在消息总线仍开放时完成异步保存或收尾。
- PluginManager 汇总进程内模块的准备状态及未就绪模块列表，支持取消。
- ProcessRuntime 注册 prepareExitSupported 能力，处理 prepareExit / exitReadiness / cancelPrepareExit，通过 requestId 隔离不同轮次；回调异常或控制帧发送失败进入退出处理。
- ProcessSupervisor 的手动停止、重启先等待退出准备。30 秒未完成则取消操作、保留进程；增加 stopFinished 信号。应用退出准备期间暂停自动重启，取消退出后恢复；旧子进程未声明能力时沿用原有停止流程。
- MainWindow 关闭先启动退出准备，每 200 ms 查询一次；30 秒未完成取消关闭并提示模块列表。就绪后仍执行进程内 UI 的 canClose(ApplicationExit)；否决时取消准备。
- ProcessWindowHost 释放嵌入窗口前解除原生父窗口关系，并保留 QObject 生命周期托管；MainWindow 在 Stopping 状态即清理窗口宿主。
- 子进程环境增加 QFRAMEWORK_APP_DIR，指向主程序目录。
- IPC 中文错误字面量显式使用 UTF-16；框架、SDK 和主程序入口的阅读导引与注释一并同步。
- 应用工程移除四个不存在的业务模块项目引用，并同步 Qt Network 运行库复制步骤。
- 移植通用框架回归测试；原业务训练窗口用例改用 ProcessUiExample。保留当前示例模块的测试工程引用。

框架本体、SDK 和主程序 main.cpp 的 C++ 文件与源工程逐文件哈希一致。消息总线、日志、配置解析等多处文件的差异仅为注释或排版，不代表功能优化；QueueCapacity / MaxMessageBytes 为 0 的回退规则不变。

## 接口兼容注意
